# 落書き生成（generator）

2026年11月20日版（出力の寸法 1330 × 1030 mm。原作の画面から言葉にした組み合わせ方のルールを追加）

## 使い方

```bash
cd ~/Desktop/generator
./run.sh
```

1枚生成して `~/graffiti/output/latest.svg` を上書きします。実行のたびに違う絵が出ます。

同じ絵をもう一度出したいときは番号を渡します。実行時に表示される `seed=...` の数字です。

```bash
./run.sh 12
```

## 出力

| | |
|---|---|
| 場所 | `~/graffiti/output/latest.svg`（毎回上書き） |
| 寸法 | **横 1330 × 縦 1030 mm**（横長。最終出力の大きさ） |
| 中身 | `<polyline>` の並び。1本の線が1つの polyline |
| 線の数 | 1段のとき 9〜13 本／2段のとき 14〜27 本（中央20。重なりで切れて増えた線は数えない） |

座標の原点は左上、単位は mm です。

## 必要なもの

- Python 3
- numpy

それだけです。scikit-learn などは要りません。

```bash
pip3 install numpy
```

## ファイル

| | |
|---|---|
| `run.sh` | これを叩く |
| `make_one.py` | 1枚生成して SVG を書く |
| `graffiti_gen.py` | 生成の本体。設定（`P`）もここ |
| `model.pkl` | 学習結果。写真から取り出した線と、その分類 |
| `marks.pkl` | 学習データの中の本物の印（写真に描かれていた、交差した2本の小さい線）。`model.pkl` とは別に置く。無ければ印は入らない |

`model.pkl` だけを差し替えれば、学習し直した結果に切り替わります。

`marks.pkl` は `graffiti-brain` で `python3 -c "import graffiti_gen as gg; gg.make_marks('pieces.pkl', '../generator/marks.pkl')"` を実行すると作れます（学習し直しは要りません）。`train_model.py` を実行したときも一緒に作られます。

## 何をしているか

1. `model.pkl` から、写真で学習した線とその分類を読む
2. 同じグループの近い線を3本混ぜて、新しい形を作る
3. 文字の輪郭を作る。作り方は2通りで、文字ごとに半々で選ぶ
   - a. 大きい輪郭の線（文字まるごとの輪郭）を3本混ぜたもの。学習データに近すぎる形は引き直す。そのうち3〜4割は、輪郭を2つ続けて「1本の線で2文字ぶん」にする
   - b. 小さい線を混ぜた形をいくつか繋いで、丸みのある長い一本の線にしたもの
4. 輪郭に線を0〜2本足して1文字にする（a は小さい線を中に置く。b は丸い線を重ねて縦に立てる）
5. 文字を2〜8個並べて単語にする
6. 単語を2〜3個、1〜2段に配置する（段数は確率で決まる。2段なら上下を区切る）
7. 横に広げて枠の端に合わせる
8. 大きく空いているところに線を足す
9. 条件に合わなければ 1 からやり直す
10. 枠に合わせて大きさを揃え、SVG に書き出す

条件（線の本数・絵の縦横比・中の空白）に合うまで作り直します。1枚あたり 0.5 秒ほどです。400回ためして合わなければ、いちばん近いものを出します。

## 原作の画面から言葉にした組み合わせ方のルール（11/18）

| | 既定 | 効果 |
|---|---|---|
| `occlude` | True | 重なった所は描かない。前にある文字の輪郭の内側に入った、後ろの文字の線を消す。線が交差せず突き当たりで止まる |
| `front` | None | どちらの文字が前か（"left" / "right"）。None なら1枚ごとにくじ |
| `rowfrac` | (0.40,0.60) | 2段のとき、下の段が使う高さの割合。段の高さはそろえない（片方は小さい文字がたくさん、もう片方は大きい文字が少し）。片方の段だけ大きくなりすぎないよう、大きいほうでも小さいほうの1.5倍まで（11/20 に 0.35〜0.65 から） |
| `wrow` | (1,3) | 2段のとき、1段に置く単語の数。文字の数は段の幅に入る数だけ作る |
| `pmark` | None | 印（写真に描かれていた、交差した2本の小さい線）が入る確率。None なら学習データの割合（今は29枚中2枚、約7%）。形は学習データの本物の印から、他の線と同じく近い線と混ぜて作る |
| `fmargin` / `xmargin` / `ymargin` | 0.01 | 余白。原作は枠の端まで描いている |
| `maxsingle` | 2 | 1本だけの文字は1枚に2文字まで |
| `singlemax` | 0.45 | 1本だけの文字を作ってよいのは、文字の高さが枠の高さの45%以下のときだけ（2段の大きいほうの段では作らない） |
| `minlet` | 3 | 1語の段の、単語の文字数の下限（2語に分けた段は `minlet2`） |
| `fillgap2` | False | 2段のときは空いた所を埋めない（1文字だけぽつんと置かれるため） |
| `maxhide` | 0.30 | 重なりで隠れてよいのは1文字の線のこの割合まで。超えるときは後ろの文字を横にずらしてから重ねる。重なりで切れて増えた線は、線の本数の条件で数えない |
| `minstk1` | 2 | 1段のときは1本だけの文字を作らない |
| `row1h` | 0.50 | 1段のとき、帯の高さ（枠の高さに対する割合）。帯は上下の真ん中あたりに置き、帯の幅に入る数だけ文字を作る。None なら枠いっぱい（約1mの文字になり不自然だった） |
| `minwidth1` | 0.85 | 1段の帯の長さの下限（枠の幅に対する割合）。短い帯は作り直す。帯の文字は3つ以上 |
| `nline1b` | (9,16) | 1段を帯にするときの線の本数。8本以下は寂しい |
| `minink1` | 5.0 | 1段を帯にするとき、線の総延長の下限（枠の高さに対する倍数）。下回る絵は寂しいので作り直す |
| `lnarrow` | 1.00 | 文字を横に縮める倍率。0.7 は細長く詰め込まれた感じになり採らなかった |

## 絵の調子を変えたいとき

`graffiti_gen.py` の先頭にある `P` の値を変えます。**学習し直す必要はありません。**

| | 既定 | 効果 |
|---|---|---|
| `nword` | (2,4) | 単語の数（2〜3） |
| `nlet` | (2,9) | 1単語の文字数（2〜8） |
| `pstk` | (.30,.55,.15) | 大きい輪郭の文字が何本の線でできるかの確率（輪郭だけ／＋中の線1本／＋2本） |
| `pstkr` | (.75,.25) | 小さい線を繋いだ丸い線の文字が何本でできるかの確率（1本/2本）。3本重ねると団子になる |
| `pbig1` | 0.75 | 1段のときの `pbig`。1段は文字が1m近くになるので、大きい輪郭の文字を主にする |
| `minbig1` | 0.50 | 1段のとき、文字のうち大きい輪郭の文字が占める割合の下限。下回る絵は作り直す（全体として文字に見えるように） |
| `nword1` / `nlet1` | (1,2) / (2,4) | 1段のときの単語の数（1つ）と文字数（2〜3）。この枠に入る数だけ作る |
| `pstk1` | (.30,.45,.25) | 1段のときの `pstk`。文字が少ないので、輪郭の中の線を増やす |
| `bigopen1` | 0.70 | 1段のとき、大きい輪郭として使ってよい開き具合の上限。開いた弧は引き直す |
| `minclosed1` | 1 | 1段のとき、閉じかけた輪郭（開き具合 `closedgap`=0.55 以下、または2文字ぶん続けた輪郭）の文字がいくつ以上要るか |
| `pjoin1` | 0.50 | 1段のときの `pjoin`。2文字ぶん続けた輪郭を増やして形を複雑にする |
| `minwig1` | 2.5 | 1段のとき、輪郭の「こぶ・くぼみ」の量の下限。つるんとした楕円が並ぶだけの絵は作り直す |
| `mincross1` | 3 | 1段のとき、線どうしが交わる回数の下限。文字が離れて並ぶだけの絵は作り直す |
| `minstk` | 1 | 1文字の線の本数の下限（2文字ぶん続けた輪郭は minstk+1 本以上） |
| `binmin` | 0.45 | 輪郭の中に置く線の大きさの下限（輪郭に対する割合）。短い線にならないように |
| `binmax` | 0.60 | 輪郭の中に置く小さい線の大きさの上限（輪郭に対する割合） |
| `lsize` | 0.95 | 2段のときの1文字の高さ |
| `lsize1` | 0.95 | 1段のときの1文字の高さ |
| `lvar` | (0.92,1.08) | 文字ごとの高さのばらつき。原作は段の中で高さがそろっている |
| `mixsame` | True | 大きい輪郭の線を混ぜるとき、閉じかけは閉じかけどうし、開いた線は開いた線どうしで、描く向きと描き始めをそろえて混ぜる。そのまま混ぜると閉じた輪郭が開き、上が開いた（Uの字のような）文字が学習データの2倍以上出ていた（11/20） |
| `wrow` | (1,3) | 2段のとき、段ごとに1語か2語かをくじで決める。片方の段だけ2語、両方2語、どちらも1語が混ざる。1段の帯は1語 |
| `wlet2` | (2,4) | 2語に分けた段の1語の文字数。その段は、収まるまで文字を小さくする（縦横の比は変えない） |
| `wtot2` | (5,6) | 2語に分けた段の、段全体の文字数。2文字＋2文字の小さな玉が並ぶのを避ける |
| `wdiff` / `wgdiff` | 0.15 / 0.15 | 上下とも2語のとき、単語の切れ目の位置とすきまの広さを上下で変える（田の字に並ばないように） |
| `all_like1` | True | 2段の絵のどの段も、1段の帯と同じく、輪郭は大きい輪郭の線から（`pbig2`=1.0）、開きすぎない形だけ（`bigopen1`=0.70）で作る。開いた線や小さい線をつないだ輪郭は文字に見えなかった（11/20） |
| `split_like1` | True | 2語に分けた段の文字は、さらに1文字2本以上（`minstk2`=2） |
| `wgap` | (0.25,0.70) | 2語の段の、単語どうしのすきま（文字の高さに対する割合）。段ごとにくじ。上限は `wgapmax`=0.90 |
| `minlet2` | 2 | 2語に分けた段の1語の文字数の下限 |
| `contact` | (0.10,0.22) | 単語の中の文字を、線どうしで寄せる。高さごとに前の文字の右端と次の文字の左端を比べ、線が文字の高さのこの割合だけ食い込むように置く。文字どうしが触れて1つの単語に見える（11/20）。段の中身が段の幅に届かないときは、段の真ん中に置く |
| `gap` | −0.35 | 文字どうしの重なり（文字の高さに対する割合）。`contact` で置けないとき（同じ高さに線がないとき）だけ使う |
| `turns` | (0.8,1.3) | 2本以上でできる字の、線の巻き具合 |
| `turns1` | (1.1,1.6) | 1本だけでできる字の巻き具合 |
| `p1row` | 0.20 | 1段になる確率 |
| `pbig` | 0.80 | 文字の輪郭に「大きい輪郭の線を混ぜたもの」を使う確率。0 にすると小さい線を繋いだ丸い線だけ（11/3 までの作り方） |
| `mixbig` | 3 | 大きい輪郭の線を混ぜる本数。写しを避けるのは `dmin` が受け持つので、3 である必要はない |
| `pjoin` | 0.35 | 大きい輪郭の文字を、1本の線で2文字ぶん続けて描いた輪郭にする確率。0 なら1文字1本 |
| `dmin` | 0.15 | 混ぜた輪郭が学習データのどの線ともこれ以上離れているものだけ使う（写しを避ける） |
| `bigasp` | (0.55,1.25) | 大きい輪郭の線の横/縦の範囲。平たい線は文字に使わない |
| `rowsplit` | True | 2段のとき上下を区切って交わらせない |
| `rowsep` | 0.03 | そのときの段どうしのすきま |
| `xspread` | 1.0 | 横に広げて端に合わせる度合い。単語→文字の順に広げる |
| `xletmax` | 0.00 | 文字どうしを広げてよい上限（文字幅に対する割合） |
| `cap` | 1.60 | 枠に合わせて拡大してよい上限 |
| `loose` | 0.45 | 置き場所の自由さ |
| `dnear` | 0.18 | ポツンと置く線を、他の線からどれだけ離してよいか |
| `mix` | 3 | 形を混ぜるときに使う線の数。1 だと学習データのコピー |

**条件（これに合うまで作り直す）**

| | 既定 | 効果 |
|---|---|---|
| `nline` | (13,22) | 2段のときの線の本数を 13〜21 にする（重なりで切れて増えた線は数えない） |
| `nline1` | (6,11) | 1段のときの線の本数 |
| `maxover` | 1.00 | 段からあふれてよい度合い。1段に置いた単語の幅の合計が段の幅を超える絵は作り直す（単語どうしが重なって団子になるため） |
| `maxcrowd` | 5 | 枠を 10×10 のマスに切ったとき、1マスを通ってよい線の本数 |
| `maxshort` | 3 | 短い線（枠の高さの `shortsz`=0.13 より小さい線）は1枚に何本までか。「＋」は2本で1つと数える |
| `aspect` | (1.17,1.41) | 絵の縦横比。枠は 1.291 |
| `maxhole` | 0.50 | 絵の中に空いてよい正方形の大きさ |
| `ntry` | 400 | 何回まで作り直すか |

**空いたところを埋める**

| | 既定 | 効果 |
|---|---|---|
| `fillgap` | True | 空白に線を足して埋める |
| `fillto` | 0.30 | どこまで埋めるか（空白がこの大きさ以下になるまで） |
| `fillmax` | 3 | 足してよい本数 |
| `fillsize` | 0.80 | 足す文字の大きさ（空白に対する割合） |

寸法を変える場合は同じファイルの `MM_W` / `MM_H` です。寸法を変えたら `aspect` も新しい枠の比（`MM_W / MM_H`）をはさむ範囲に直します。そのとき、1単語の文字数（3前後）と単語の横縦比（1.2〜1.7）が保たれているかも確かめてください。比だけ合わせると、枠が正方形に近いときに単語が「大きな文字2つ」に崩れます。

## 学習し直すとき（写真が増えたとき）

```bash
cd ~/Desktop/graffiti-brain
python3 train_model.py
```

`~/Desktop/generator/` の `model.pkl` と `graffiti_gen.py` が置き換わります。

## 不具合のとき

- `ModuleNotFoundError: numpy` → `pip3 install numpy`
- `permission denied` → `chmod +x run.sh`
- `model.pkl` が無いと言われる → このフォルダの中にあるか確認
- 絵が出ない／空っぽ → `python3 make_one.py 0` を実行して、エラーの文面を送ってください
