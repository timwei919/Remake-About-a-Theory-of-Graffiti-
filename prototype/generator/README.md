# 落書き生成（generator）

2026年11月2日版

## 使い方

```bash
cd ~/Desktop/generator
./run.sh
```

1枚生成して `~/graffiti/output/latest.svg` を上書きします。実行のたびに違う絵が出ます。

同じ絵をもう一度出したいときは番号を渡します。実行時に表示される `seed=...` の数字です。

```bash
./run.sh 12
```

## 出力

| | |
|---|---|
| 場所 | `~/graffiti/output/latest.svg`（毎回上書き） |
| 寸法 | **1030 × 710 mm**（横長。黒いフレームの内側） |
| 中身 | `<polyline>` の並び。1本の線が1つの polyline |
| 線の数 | 5〜10 本 |

座標の原点は左上、単位は mm です。

## 必要なもの

- Python 3
- numpy

それだけです。scikit-learn などは要りません。

```bash
pip3 install numpy
```

## ファイル

| | |
|---|---|
| `run.sh` | これを叩く |
| `make_one.py` | 1枚生成して SVG を書く |
| `graffiti_gen.py` | 生成の本体。設定（`P`）もここ |
| `model.pkl` | 学習結果。写真から取り出した線と、その分類 |

`model.pkl` だけを差し替えれば、学習し直した結果に切り替わります。

## 何をしているか

1. `model.pkl` から、写真で学習した線とその分類を読む
2. 同じグループの近い線を3本混ぜて、新しい形を作る
3. その形をいくつか繋いで、丸みのある長い一本の線にする
4. その線を1〜3本重ねて1文字にし、縦に立てる
5. 文字を2〜8個並べて単語にする
6. 単語を2〜3個、1〜2段に配置する（段数は確率で決まる。2段なら上下を区切る）
7. 横に広げて枠の端に合わせる
8. 大きく空いているところに線を足す
9. 条件に合わなければ 1 からやり直す
10. 枠に合わせて大きさを揃え、SVG に書き出す

条件（線の本数・絵の縦横比・中の空白）に合うまで作り直します。1枚あたり 0.5 秒ほど、
作り直しは中央値で20回です。400回ためして合わなければ、いちばん近いものを出します。

## 絵の調子を変えたいとき

`graffiti_gen.py` の先頭にある `P` の値を変えます。**学習し直す必要はありません。**

| | 既定 | 効果 |
|---|---|---|
| `nword` | (2,4) | 単語の数（2〜3） |
| `nlet` | (2,9) | 1単語の文字数（2〜8） |
| `pstk` | (.55,.30,.15) | 1文字が何本の線でできるかの確率（1本/2本/3本） |
| `lsize` | 0.95 | 2段のときの1文字の高さ |
| `lsize1` | 0.95 | 1段のときの1文字の高さ |
| `lvar` | (0.70,1.25) | 文字ごとの高さのばらつき |
| `gap` | −0.15 | 文字どうしの重なり |
| `turns` | (0.8,1.3) | 2本以上でできる字の、線の巻き具合 |
| `turns1` | (1.1,1.6) | 1本だけでできる字の巻き具合 |
| `p1row` | 0.30 | 1段になる確率 |
| `rowsplit` | True | 2段のとき上下を区切って交わらせない |
| `rowsep` | 0.03 | そのときの段どうしのすきま |
| `xspread` | 1.0 | 横に広げて端に合わせる度合い。単語→文字の順に広げる |
| `xletmax` | 0.15 | 文字どうしを広げてよい上限（文字幅に対する割合） |
| `cap` | 1.60 | 枠に合わせて拡大してよい上限 |
| `loose` | 0.45 | 置き場所の自由さ |
| `dnear` | 0.18 | ポツンと置く線を、他の線からどれだけ離してよいか |
| `mix` | 3 | 形を混ぜるときに使う線の数。1 だと学習データのコピー |

**条件（これに合うまで作り直す）**

| | 既定 | 効果 |
|---|---|---|
| `nline` | (5,11) | 線の本数を 5〜10 にする |
| `aspect` | (1.20,1.70) | 絵の縦横比。枠は 1.451 |
| `maxhole` | 0.50 | 絵の中に空いてよい正方形の大きさ |
| `ntry` | 400 | 何回まで作り直すか |

**空いたところを埋める**

| | 既定 | 効果 |
|---|---|---|
| `fillgap` | True | 空白に線を足して埋める |
| `fillto` | 0.30 | どこまで埋めるか（空白がこの大きさ以下になるまで） |
| `fillmax` | 3 | 足してよい本数 |
| `fillsize` | 0.80 | 足す文字の大きさ（空白に対する割合） |

寸法を変える場合は同じファイルの `MM_W` / `MM_H` です。横長で使う前提なので、縦長にするならこの2行を入れ替えます。

## 学習し直すとき（写真が増えたとき）

```bash
cd ~/Desktop/graffiti-brain
python3 train_model.py
```

`~/Desktop/generator/` の `model.pkl` と `graffiti_gen.py` が置き換わります。

## 不具合のとき

- `ModuleNotFoundError: numpy` → `pip3 install numpy`
- `permission denied` → `chmod +x run.sh`
- `model.pkl` が無いと言われる → このフォルダの中にあるか確認
- 絵が出ない／空っぽ → `python3 make_one.py 0` を実行して、エラーの文面を送ってください
