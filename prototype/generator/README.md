# 落書き生成（generator）

2026年10月28日版

## 使い方

```bash
./run.sh
```

1枚生成して `~/graffiti/output/latest.svg` を上書きします。実行のたびに違う絵が出ます。

同じ絵をもう一度出したいときは番号を渡します。

```bash
./run.sh 12
```

## 出力

| | |
|---|---|
| 場所 | `~/graffiti/output/latest.svg`（毎回上書き） |
| 寸法 | **820 × 860 mm**（黒いフレームの内側） |
| 中身 | `<polyline>` の並び。1本の線が1つの polyline |

座標の原点は左上、単位は mm です。

## 必要なもの

- Python 3
- numpy

それだけです。scikit-learn などは要りません。

```bash
pip3 install numpy
```

## ファイル

| | |
|---|---|
| `run.sh` | これを叩く |
| `make_one.py` | 1枚生成して SVG を書く |
| `graffiti_gen.py` | 生成の本体 |
| `model.pkl` | 学習済みのデータ。写真から作った線と、その分類が入っている |

`model.pkl` だけを差し替えれば、学習し直した結果に切り替わります。他のファイルはそのままで構いません。

## 何をしているか

1. `model.pkl` から、写真で学習した線とその分類を読む
2. 同じグループの近い線を混ぜて、新しい形を作る
3. その形をいくつか繋いで、丸みのある長い一本の線にする
4. その線を1〜2本重ねて1文字にし、縦に立てる
5. 文字を2〜3個重ねて並べ、単語にする
6. 単語を2〜3個、1〜2段に配置する
7. SVG に書き出す

1枚あたり1秒かかりません。

## 絵の調子を変えたいとき

`graffiti_gen.py` の先頭にある `P` の値を変えます。よく使うもの:

| | 既定 | 効果 |
|---|---|---|
| `nword` | (2,4) | 1枚の単語の数。増やすと密になる |
| `nlet` | (2,4) | 1単語の文字数 |
| `lsize` | 0.60 | 1文字の大きさ。上げると大きくなる |
| `gap` | −0.15 | 文字どうしの重なり。マイナスが大きいほど重なる |
| `turns` | (0.6,1.0) | 線の丸み。上げると巻きが強くなる |
| `ndot` | (0,2) | ポツンと置く小さい線の数 |

寸法を変える場合は同じファイルの `MM_W` / `MM_H` です。

## 不具合のとき

- `ModuleNotFoundError: numpy` → `pip3 install numpy`
- `model.pkl` が無いと言われる → このフォルダの中にあるか確認
- 絵が出ない／空っぽ → `python3 make_one.py 0` を実行して、エラーの文面を送ってください
