# 生成システム(機械学習によるスローアップ生成)

落書き(スローアップ)の写真から線の形と並び方を学習し、新しいスローアップを生成して SVG で出力する。

- 出力:`~/graffiti/output/latest.svg`(300mm × 230mm)
- 1回実行するごとに、同じパス・同じ名前で上書きされる
- 生成にかかる時間は1秒未満

学習は生成担当(藁科)の環境で行い、その結果を `model.pkl` として同梱している。このフォルダでは**生成だけ**を行うため、写真も学習処理も不要。

---

## 1. セットアップ(最初の1回だけ)

Python 3 と、2つのライブラリが必要。

```bash
pip3 install numpy scikit-learn
```

実行権限を付ける。

```bash
cd prototype/generator
chmod +x run.sh
```

動作確認。

```bash
./run.sh
```

成功すると、出力したファイルのパスが1行表示される。

```
/Users/(ユーザー名)/graffiti/output/latest.svg
```

---

## 2. 使い方(Max/MSP から)

次のコマンドを叩くと、1枚生成して SVG を上書きする。

```bash
/(このリポジトリを置いた場所)/prototype/generator/run.sh
```

- 出力先のフォルダは、なければ自動で作られる
- 書き込みは一時ファイル経由なので、書き込み途中のファイルを読む心配はない
- 正常終了すると終了コード 0 を返す

---

## 3. ファイルの構成

| ファイル | 役割 |
|---|---|
| `make_one.py` | 1枚生成して SVG を上書きする(生成処理の本体) |
| `run.sh` | `make_one.py` を呼ぶ起動スクリプト |
| `model.pkl` | 学習済みモデル |

---

## 4. 設定の変更

`make_one.py` の先頭で変更できる。

```python
OUT_DIR     = os.path.expanduser("~/graffiti/output")  # 出力先フォルダ
OUT_NAME    = "latest.svg"                             # ファイル名
W_MM, H_MM  = 300.0, 230.0                             # 描画サイズ(mm)
MARGIN      = 10.0                                     # 余白(mm)
STROKE_MM   = 1.2                                      # 線の太さ(mm)
TEMPERATURE = 0.5                                      # ばらつき(小さいほど学習データに近い)
```

---

## 5. 学習データの更新

写真を増やしたら、生成担当が学習し直して `model.pkl` を差し替える。出力形式も実行方法も変わらないため、Max 側の設定変更は不要。

---

## 6. 生成の仕組み

**学習**(生成担当の環境で実施済み)
1. 写真からスプレーの道すじを一筆書きの線として抽出する(骨格化 → ヒゲの除去 → 分岐点での連結)
2. 各線を32点の座標(64次元)で表し、主成分分析(PCA)で形の変化の軸に圧縮する
3. ガウス混合モデル(GMM)で、線の形のグループとそのばらつきを学習する(グループ数は BIC で自動決定)
4. 線の並びの遷移確率(マルコフ連鎖)と、線同士の間隔・位置の分布を学習する

**生成**(`make_one.py` が実行する)

5. 学習した確率で線の並びを決め、各グループの分布から形をサンプリングし(カーネル密度推定)、学習した位置に配置する

実行するたびに異なる形が出力される。

現在のモデル:撮影写真14枚から一筆158本を学習。PCA で64次元を7次元に圧縮(情報保持99%)、GMM が6グループを自動検出。

---

## 7. 困ったとき

**`No module named sklearn`**
→ `pip3 install numpy scikit-learn`

**`permission denied: ./run.sh`**
→ `chmod +x run.sh`

**`model.pkl がありません`**
→ `model.pkl` が `make_one.py` と同じフォルダにあるか確認する

**Max から実行すると動かない(ターミナルからは動く)**
→ Max から起動されたシェルは `python3` の場所を認識できないことがある。`which python3` の結果を確認し、`run.sh` の次の行を絶対パスに書き換える。

```bash
PY="$(command -v python3 || echo /usr/bin/python3)"
```

↓

```bash
PY="/opt/homebrew/bin/python3"   # 例
```
