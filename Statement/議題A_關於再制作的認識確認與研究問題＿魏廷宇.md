# 議題A:關於再制作的認識確認與研究問題

---

## 1. 「再制作」是在做什麼

### 1-1. 立場確認

在媒體藝術保存與傳承的脈絡中，大致有以下光譜:

| 立場      | 內容                 |
| ------- | ------------------ |
| 修復      | 將特定的原作物件與器材直接修復並展示 |
| 再展示     | 向作家借出器材、資料（原作）再次展出 |
| 忠實再現    | 復原規格，重新做出同一體驗      |
| 再詮釋、再制作 | 保住核心，置換手段與脈絡       |
| 致敬/挪用   | 把核心移植到別的形式         |

**我的立場**:這個再製作計劃是「テクノロジーの〈解釈学〉」當中的實踐，因此目標不是單純再製作，而是在這個過程中透過實踐的方式，建立自己對於テクノロジーの〈解釈学〉的觀點與立場。因此我認為立場比較接近「忠實再現」和「再詮釋、再制作」之間。必須不向作家索取資料，只靠公開資料進行。站在「假如作家已經不在世」的思考實驗上。如果因為藝術家活著就直接索取資料，那就會淪為「再展示」。同時我認為目標不是完全複製或再現作品，而是**掌握原作當中，人們被打動的核心(感動點是什麼？)，在可能範圍內還原**，但不追求無止盡地還原。

制作中不去詢問藝術家，而是在展示階段才邀請，是再解釋的核心價值。

### 1-2. 食譜(レシピ)是什麼?

事前聯絡的客觀事實:やんツーさん親口說**「作品のインストラクションは作っていませんが、断片的にプロッターのパーツやポンプのパーツ、システムのデータは残っています。」**。也就是說,本作不存在食譜**。留下的只有斷片(零件、資料)與公開紀錄。

由此可以導出這次再製作的一個核心任務，就是逆寫食譜的這個行為。因此成果物不能只是再製作之後的藝術作品展示，逆寫後的食譜也應該被納入同樣重要程度的展示思考以及檔案化。這也回應了テクノロジーの〈解釈学〉當中「解釋」的姿態。

**如何紀錄這份逆寫的食譜，範圍到哪？該如何紀錄？如何展示？是未來重要的課題。**

## 2.如何觀看此次再製作的計劃？

想像觀眾到了展場，他們可以看到哪些事物？

1. **作品本身**:
	1. 線條本身：機器學習後的機器繪製線條
	2. 時間結構：繪製的時間、乾燥的時間
	3. 機械的生命感：透過單一極簡行為的反覆，是否會有類似生命的感受？
	4. 系統的內面：顯示器上顯示了控制軟體、機器學習軟體以及頂部拍攝下來的 Webcam 畫面。回應了 OIST 展時藝術家本人自述的講究:「MaxMSPのパッチみたく注意深く追ってくと何がどうなってんのかわかる配線が今回のセッティングこだわりポイントでございます」([Instagram,2017年11月](https://www.instagram.com/p/BbBK_ktjmh7/))。機制的透明性本身也是觀賞對象。
	5. 聲音：機器運轉的聲音，電風扇啟動的聲音。這些聲音直接連結到了空間中濕度的狀態。
2. **再製作的計劃**:
	1. 事前研究：為什麼挑選這件作品？
	2. 怎麼進行作品的食譜逆寫？
	3. 如何掌握需要被重新呈現出來的要素？
	4. 當時（2017）與現在（2026）的技術、語境有什麼不同？

## 3. 我想達成什麼

### 4-1. 同一性的三層

- **結構的同一性**：知覺→描畫→蒸發的循環邏輯運作相同
- **體驗的同一性**：觀眾獲得與2017年觀眾相近的體驗(線的質感、節奏、簡易生命的規律感
- **概念的同一性**：蜱蟲/塗鴉客的比喻對2026年的觀眾依然成立

### 4-2. 「把10年前的機械學習語彙置回當下脈絡」的具體內容

2017年的脈絡：展覽《大いなる日常（The Great Ordinary）》的那年。「機械學習」還很稀罕，非監督式學習(clustering)抽出線的特徵、輸出「像那麼一回事」的線，這件事本身就有驚奇。那是「AI能否判斷美」被當作問題的時代。

2026年的脈絡：生成式AI日常化，「AI會畫畫」已無人驚訝，甚至生成式人工智慧已經是大家生活中不可或缺的助理。因此個人推測《落書きの原理について》這件作品被再製作反而是作為對大規模模型之過剩的對照，大眾可能會覺得新鮮，或是像是看到文物的復古懷舊感。

**這個技術與時代差異的觀察，是再製作本身之外，基於這件作品獨立出來人要被紀錄的觀者心得。**
### 4-3. 對於原作藝術家

對於原作藝術家，我希望能夠記錄下一位藝術家看到自己的作品被再製作的心得與想法。一件作品被研究的方式重製是很珍貴的經驗，所以**在展示之後，紀錄下原作藝術家的觀點與想法很重要。**

### 5-2. 《落書きの原理について》在這套系譜中的特點

從系譜中可以發現，機器學習的脈絡並不是此作才發展。在之前的作品就已經開始，《落書きの原理について》別之處不是機器學習，而是時間性。

這件作品是唯一內建「消失」的作品。其他作品用噴漆、塗料，痕跡會留下。只有本作把媒材換成水，把消失與再描繪的循環本身主題化。在塗鴉的本質「描繪的行為」加入了時間性，這邊說的時間性包含未完成、進行中，以及被抹消好幾種樣態。

### 5-3. 藝術家獨有的質感/他最珍視的東西

從公開資料能發現的特徵:

- **把制度性行為交由機械代行**:描繪和觀賞(《現代の鑑賞者》2018)、佈置和拆除(《永続的な一過性》2022)。本作屬於「描繪」的系列。
- **DIY、hack 的手感**：改造現有電器製品。例如，電動滑板、現成雷射切割機軟體。並非完全自製工具的創作。
- **機制的裸露**：常常讓人直接看見配線與 patch 畫面。
- **對未完成之線的愛**：本人的話

> 「スローアップと呼ばれる類の幅のあるモコっとしたスタイルのグラフィティのストロークの軌道をシステムが学習して、形のある図形になりそうでならないもにょもにょした線、スローアップの気配をコンクリートブロックの上に水を使って書き続ける作品です。」
> ——[やんツー Instagram、2017年2月18日](https://www.instagram.com/yang02/p/BQpf_AOFCcl/)

> 「人工知能がデータから学習して書く線が非常にのびやかで豊かな表情を見せていて、あと水がつくる線の濃淡も味わいがあって思いの外すごい良い作品になってた。」
> ——[同投稿へのコメント、2017年2月27日](https://www.instagram.com/yang02/p/BQpf_AOFCcl/)

他珍視的可能不是畫得好，而是某種帶有生氣和運動的質感。
