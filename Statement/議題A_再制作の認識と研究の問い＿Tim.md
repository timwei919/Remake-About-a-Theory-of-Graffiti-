# 議題A:再制作についての認識の確認と研究の問い

---

## 1. 「再制作」とは何をすることか

### 1-1. 立場の確認

メディアアートの保存と継承の文脈には、おおよそ次のようなスペクトラムがある。

| 立場               | 内容                       |
| ---------------- | ------------------------ |
| 修復               | 特定の原作の物体・機材をそのまま修復して見せる  |
| 再展示              | 作家から機材・データ(原作)を借りて再び展示する |
| 忠実再現             | 仕様を復元し、同一の体験を作り直す        |
| 再解釈・再制作          | 核心を保ちながら、手段と文脈を置き換える     |
| オマージュ/アプロプリエーション | 核心を別の形式に移し替える            |

**私の立場**:この再制作はプロジェクト「テクノロジーの〈解釈学〉」における実践であって、単に作品を作り直すことが目的ではない。作り直すという過程をつうじて、テクノロジーの〈解釈学〉に対する自分なりの視点と立場を組み立てていくことに狙いがある。その意味で、立ち位置は「忠実再現」と「再解釈・再制作」のあいだにあると考えている。作家に資料を求めず、公開資料のみで進めなければならない。「作家がもし亡くなっていたら」という思考練習に立つためである。存命だからといって資料をもらってしまえば、それは「再展示」に落ちてしまう。また、目指すのは作品の完全な複製や再現ではなく、**原作のなかで人の心を動かしている核心(何に感動しているのか?)を掴み、可能な範囲で再現する**ことだ。復元を無際限に追い求めることはしない。

**制作の間は作家に問い合わせず、展示の段階になってはじめて招く。ここに、再解釈としての核心的な価値があると考えている。**

### 1-2. レシピとは?

事前のやり取りでわかっている客観的な事実がある。やんツーさん本人がメールに**「作品のインストラクションは作っていませんが、断片的にプロッターのパーツやポンプのパーツ、システムのデータは残っています」**と述べていることだ。つまり、本作にレシピは存在しない。残されているのは断片(パーツ、データ)と公開された記録だけである。

ここから、今回の再制作の核心的な課題のひとつが導かれる。すなわち、レシピを逆向きに書き起こすという行為そのものである。したがって**成果物は、再制作された作品の展示だけにとどまらない。逆算で書き起こされたレシピもまた、同じ重さで展示とアーカイブ化の対象として考えられるべきだ。** これは、テクノロジーの〈解釈学〉における「解釈」の姿勢への応答でもある。

**この逆算のレシピをどう記録するか。範囲をどこまでとするか。どう展示するか。今後の重要な課題である。**

## 2. この再制作の計画は、どう見られるのか?

観客が会場に来たとき、そこで何を目にできるのかを想像してみる。

1. **作品そのもの**
	1. 線そのもの:機械学習を経て機械が描く線
	2. 時間の構造:描かれていく時間、乾いていく時間
	3. 機械の生命感:極端に単純な行為の反復から、生命に似た感覚は立ち上がるのか?
	4. システムの内面:ディスプレイには制御ソフト、機械学習ソフト、真上からのWebカメラの映像が映し出される。OISTでの展示の際、作家本人が「MaxMSPのパッチみたく注意深く追ってくと何がどうなってんのかわかる配線が今回のセッティングこだわりポイントでございます」([Instagram、2017年11月](https://www.instagram.com/p/BbBK_ktjmh7/))と述べているとおり、仕組みの透明性それ自体が鑑賞の対象になる。
	5. 音:機械の動作音、扇風機が回り出す音。これらの音は、空間の湿度の状態と直結している。
2. **再制作という計画**
	1. 事前のリサーチ:なぜこの作品を選んだのか
	2. 作品のレシピの逆算を、どう進めたのか
	3. あらためて提示すべき要素を、どう掴んだのか
	4. 当時(2017)と現在(2026)とで、技術と文脈はどう違うのか

## 3. 何を達成したいのか

### 3-1. 同一性の三つの層

- **構造**:知覚→描画→蒸発という循環のロジックが同じように動くこと
- **体験**:2017年の観客に近い体験を観客が得られること(線の質感、テンポ、簡素な生命のリズム感)
- **概念**:ダニ/グラフィティライターの比喩が、2026年の観客にも成立すること

### 3-2. 「10年前の機械学習の語彙を現在の文脈に置き直す」の中身

2017年の文脈:展覧会「大いなる日常(The Great Ordinary)」の年である。「機械学習」はまだ珍しく、教師なし学習(Clustering)が線の特徴を抽出して「それらしい」線を出力すること、それ自体に驚きがあった。「AIは美を判断できるのか」が問いとして成り立っていた時代だ。

2026年の文脈:生成AIは日常となり、「AIが絵を描く」ことに驚く人はもういない。それどころか、生成AIは生活に欠かせないアシスタントにさえなっている。だからこそ、いま《落書きの原理について》が再制作されるなら、むしろ大規模モデルの過剰さに対する対照として新鮮に映るかもしれないし、あるいは文物を目にするようなレトロな懐かしさを呼ぶのかもしれない——と個人的には推測している。

**こうした技術と時代の差をめぐる観察は、再制作そのものとは別に、この作品に基づく観客の受け取り方として独立に記録されるべきものである。**
### 3-3. 原作の作家について

原作の作家については、自作が再制作されるのを目にしたアーティストの感想と考えを記録したい。ひとつの作品が研究というかたちで作り直されるのは得がたい経験のはずであり、だからこそ**展示のあとに、原作者の視点と考えを記録することが重要になる。**

## 4. 研究:《落書きの原理について》の文脈

### 4-1. やんツーのグラフィティ/ドローイング系列の整理

| 年 | 作品 | 手段 | グラフィティから抽出したもの |
| ------- | --------------------------------- | ---------------------- | ----------------------- |
| 2009 | Urbanized Typeface | — | 都市の文字 |
| 2011 | 「落書き」のための装置 | スプレー+バネ+DCモーター | 身体性を取り除いた線の躍動 |
| 2011 | SENSELESS DRAWING BOT(菅野創と) | スプレー+二重振子+電動スケートボード | 即興性、ダイナミズム、ヴァンダリズム |
| 2012 | SENSELESS DRAWING BOT #2(菅野創と) | 高圧洗浄機 | 破壊力(消火器グラフィティの模倣) |
| 2014–15 | SEMI-SENSELESS DRAWING MODULES 系列 | センサーデータ駆動 | 環境データが生む線 |
| 2016 | 形骸化する言語 | Asemic Languages(菅野創と) | ML(文字の学習) |
| 2017 | **落書きの原理について** | **水+XYプロッター+ML+水分センサー** | **知覚と円環(描かれ、消され、また描かれる)** |

### 4-2. この系譜のなかでの《落書きの原理について》

系譜を眺めてみると、機械学習の文脈は本作で初めて現れたわけではないことがわかる。それ以前の作品ですでに始まっている。《落書きの原理について》を分かつのは機械学習ではなく、時間性である。

この作品は、系譜のなかで唯一「消えること」が組み込まれた作品だ。ほかの作品はスプレーや塗料を使うため、痕跡が残る。本作だけが媒材を水に置き換え、消失と再描画の循環そのものを主題化した。グラフィティの本質である「描くという行為」に時間性を持ち込んだのである。ここでいう時間性には、未完成であること、進行中であること、そして消されていくこと——複数の様態が含まれている。

### 4-3. 作家に固有の質感/彼が最も大切にしているもの

公開資料から見えてくる特徴:

- **制度にまつわる行為を機械に代行させる**:描くことと鑑賞すること(《現代の鑑賞者》2018)、設置と撤去(《永続的な一過性》2022)。本作は「描く」の系列に属する。
- **DIY・ハックの手つき**:既存の電気製品を改造する。たとえば電動スケートボード、既製レーザーカッターのソフト。道具を一から自作するタイプの制作ではない。
- **仕組みの露出**:配線やpatchの画面を、そのまま観客に見せることが多い。
- **未完成の線への愛着**:本人の言葉

> 「スローアップと呼ばれる類の幅のあるモコっとしたスタイルのグラフィティのストロークの軌道をシステムが学習して、形のある図形になりそうでならないもにょもにょした線、スローアップの気配をコンクリートブロックの上に水を使って書き続ける作品です。」
> ——[やんツー Instagram、2017年2月18日](https://www.instagram.com/yang02/p/BQpf_AOFCcl/)

> 「人工知能がデータから学習して書く線が非常にのびやかで豊かな表情を見せていて、あと水がつくる線の濃淡も味わいがあって思いの外すごい良い作品になってた。」
> ——[同投稿へのコメント、2017年2月27日](https://www.instagram.com/yang02/p/BQpf_AOFCcl/)

彼が大切にしているのは上手く描けていることではなく、生気と運動を帯びた、ある種の質感なのだと思われる。
