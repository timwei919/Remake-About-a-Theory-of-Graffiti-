# 《落書きの原理について》再制作記録

やんツー(yang02)《落書きの原理について|About a Theory of Graffiti》(2017)の再制作プロジェクトの記録。
IAMAS 博士前期課程プロジェクト「[テクノロジーの〈解釈学〉](https://www.iamas.ac.jp/master_projects/interpretive-practices-of-technology/)」の一環として実施。

## 再制作の方針

作家に技術資料を求めず、**公開資料のみから再制作する**。「作家がもし不在であったら再制作は可能か」という前提に立つことで、単なる再展示ではなく、テクノロジーの解釈行為としての再制作を試みる。オリジナルにインストラクションは存在しないため、**公開資料から逆算してレシピを書き起こすこと自体**を成果物と位置づける。

作家ご本人からは再制作について快諾を得ており、制作過程・完成後の対話は事後の検証として行う予定。

## 作品について(公開情報)

電動ポンプで吸い上げられた水がシリコンチューブを伝い、XYプロッターのキャリッジ先端からコンクリートブロックに水滴を垂らして描画する。ブロックに取り付けられた水分センサーが湿り気/乾き具合を知覚し、乾いて描画が消失すると次の描画を開始、描き終わって濡れれば扇風機で蒸発させる——この循環を繰り返す。描かれる線は、グラフィティの「スローアップ」の造形的特徴を機械学習が学習して出力したもの。
